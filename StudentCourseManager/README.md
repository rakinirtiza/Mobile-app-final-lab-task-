# StudentCourseManager

This is an Android app made with Kotlin and Firebase Realtime Database.

## Features

- Add new course
- View all courses
- Update course information
- Delete course
- View course details
- Search courses
- Real-time database connection

## Tools and Technologies

- Kotlin
- Android Studio
- Firebase Realtime Database
- RecyclerView

## CRUD Operations

This app supports:

- Create
- Read
- Update
- Delete

## App Screens

1. MainActivity
2. AddCourseActivity
3. EditCourseActivity
4. CourseDetailActivity

## Database

Firebase Realtime Database is used to store course data.
