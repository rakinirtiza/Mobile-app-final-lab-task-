# University News App

## Overview

University News App is an Android application developed using Kotlin in Android Studio.  
The app connects to an online REST API and displays posts, comments, and user information in a clean and user-friendly interface.

This project was created as part of an Android development learning task.

---

## Features

- View all news posts
- Search posts instantly
- Open detailed post screen
- View comments for each post
- Open users screen
- Display user information
- Swipe to refresh data
- Smooth RecyclerView scrolling
- Multiple activity navigation

---

## Technologies Used

- Kotlin

- Retrofit
